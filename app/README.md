# Backend — Claude Support SAP AI

FastAPI backend that connects to the Anthropic Claude API to provide SAP support assistance.

## Quick Start

```bash
# From the project root
pip install -r requirements.txt
cp .env.example .env
# Edit .env with your ANTHROPIC_API_KEY
python -m app.main
```

The server starts at `http://localhost:8000` with interactive docs at `/docs`.
